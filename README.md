# Учёт заказов

Учебная конфигурация 1С, которая автоматизирует учёт заказов: поступление на склад, резервирование по заказам, продажи и контроль остатков

## Функциональность

- **Справочники:** Номенклатура, Контрагенты, Склады
- **Документы:**
  - Поступление товаров (увеличивает остатки)
  - Заказ клиента (резервирует товар)
  - Реализация товаров (списывает со склада и снимает резерв, может создаваться на основании заказа)
- **Регистры:**
  - Остатки товаров (физическое наличие на складе)
  - Резервы (зарезервированный под заказы товар)
  - Цены номенклатуры (история цен с привязкой к дате)
- **Отчёты:**
  - Остатки товаров (физические остатки на дату)
  - Свободные остатки (физические остатки - резервы)

## Начало работы

1. Установите платформу 1С:Предприятие 8.5 (учебная версия)
2. Скачайте файлы конфигурации из репозитория
3. В Конфигураторе выполните: **Конфигурация → Загрузить конфигурацию из файлов...**
4. Запустите 1С в режиме «Предприятие»

## Примерный сценарий использования

1. Заполните справочники (номенклатура, склады, контрагенты)
2. Внесите начальные цены в «Цены номенклатуры»
3. Оформите **Поступление товаров** - товары появятся на складе
4. Создайте **Заказ клиента** - товары зарезервируются
5. На основании заказа создайте **Реализацию товаров** - товары спишутся со склада
6. Откройте отчёт **«Свободные остатки»** - увидите, сколько реально доступно для продажи
